# zanaat.dev

Source of [zanaat.dev](https://zanaat.dev), the landing page of the
[zanaat-dev](https://github.com/zanaat-dev) organization.

This repository is the organization's GitHub Pages site. Because it holds the
`zanaat.dev` custom domain, every project site in the organization is served
under it. For example, the `lonca` repository's docs are at
[zanaat.dev/lonca](https://zanaat.dev/lonca).

Plain static HTML with no build step. Edit `index.html` and push to `main`.
